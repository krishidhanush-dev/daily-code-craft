
# Interactive Profile Card

## 📌 About
A simple profile card project built using HTML and CSS to practice layouts, hover effects, transitions, and animations.

## 🛠️ Technologies Used
- HTML5
- CSS3

## ✨ Features
- Centered profile card and profile image
- Flexbox button alignment
- Rounded profile image and card corners
- Button hover color transition
- Card hover movement using `transform`
- Smooth effects using `transition`
- Animated green status indicator using `@keyframes`
- Responsive-friendly layout basics

## 📚 Concepts Learned
- `margin: auto` for centering
- Flexbox: `display: flex`, `justify-content`, `align-items`, `gap`
- `:hover` pseudo-class
- `transform: translateY()`
- `box-shadow`
- CSS transitions and timing functions
- CSS animations, `@keyframes`, `scale()` and `opacity`

## 🎯 Learning Outcome
Learned how to combine HTML structure with CSS styling, interactive hover effects, smooth transitions, and repeating animations.
