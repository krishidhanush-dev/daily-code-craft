My Learning Cards

HTML

HTML (HyperText Markup Language) is the standard markup language used to create and structure the skeleton of web pages. It relies on a system of tags and elements to instruct web browsers on how to display content like text, links, and multimedia.

CSS

CSS (Cascading Style Sheets) is a stylesheet language used to control the presentation, layout, and visual design of documents written in HTML or XML. While HTML creates the structure and skeleton of a web page.

JavaScript

JavaScript (JS) is a lightweight, high-level, and dynamically typed programming language that serves as one of the core technologies of the World Wide Web, alongside HTML and CSS.
