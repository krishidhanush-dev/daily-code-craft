
# Responsive Cards Layout

## About
A responsive learning cards layout built using HTML and CSS. It displays three cards for HTML, CSS, and JavaScript.

## Technologies Used
- HTML5
- CSS3
- Flexbox
- Media Queries

## Concepts Learned
- Flexbox: `display: flex`, `justify-content`, `gap`, and `flex-wrap`
- Card styling using borders, padding, and border-radius
- Responsive container using `width`, `max-width`, and `margin`
- Flex properties: `flex-grow`, `flex-shrink`, and `flex-basis`
- Media queries for mobile layouts

## Features
- Three learning cards
- Responsive layout for different screen sizes
- Mobile-friendly card arrangement

## What I Learned
I learned how to create a card layout using Flexbox and make it responsive for mobile and desktop screens.
