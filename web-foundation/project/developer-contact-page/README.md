# Developer Connect

A simple developer contact page built using semantic HTML and HTML forms.

## Concepts Practiced

### Semantic HTML

Used semantic elements to give meaningful structure to the webpage.

- `<header>` → Introductory/top content
- `<nav>` → Navigation links
- `<main>` → Primary content
- `<section>` → Related content grouping
- `<article>` → Self-contained content
- `<aside>` → Related/secondary content
- `<footer>` → Ending/supporting information

### HTML Forms

Built a contact/registration form using:

- `<form>` → Form container
- `<label>` → Input description
- `<input>` → User input
- `<textarea>` → Long/multi-line text
- `<select>` → Dropdown
- `<option>` → Dropdown option
- Radio buttons → Single choice
- Checkboxes → Multiple choices
- `<button>` → Form actions

### Form Attributes Practiced

- `id` → Identifies an HTML element and connects labels
- `for` → Connects `<label>` with an input's `id`
- `name` → Identifies form data
- `value` → Represents the submitted/current value
- `placeholder` → Provides input hint
- `required` → Makes a field mandatory
- `action` → Defines where form data is sent
- `method` → Defines how form data is submitted

## Form Methods

### GET
Used mainly for retrieving/searching data.
Form data may appear in the URL.

### POST
Used mainly for submitting data to the server.
Data is sent in the request body.

## What I Learned

- How to structure a webpage using semantic HTML.
- How to create accessible label-input connections.
- How different form controls work.
- Difference between `id` and `name`.
- Difference between GET and POST.
- How radio buttons and checkboxes work.
- How form data is prepared for backend processing.
