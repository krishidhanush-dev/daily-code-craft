# 🔐 Mini Authentication Project

A beginner-friendly authentication practice project built using HTML, CSS, and JavaScript.

## 🚀 Features

- Login page
- Register page
- Login ↔ Register navigation
- Form validation
- Password confirmation
- User data storage using `localStorage`
- JSON conversion using `JSON.stringify()`
- JSON retrieval using `JSON.parse()`
- Login verification using saved credentials

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser `localStorage`

## 🧠 Key Learnings

### Form Validation

Used JavaScript to validate required fields.

### JavaScript Objects

Created a user object to store registration data.
