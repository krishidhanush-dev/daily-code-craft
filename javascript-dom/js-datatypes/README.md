## Lesson 1.3 — Data Types ✅

- **String:** Text written inside quotes, e.g., `"Dhanush"` or `"100"`.
- **Number:** Numeric values, e.g., `21` or `100`.
- **Boolean:** Either `true` or `false`.
- **Undefined:** A variable declared without an assigned value.
- **Null:** An intentional empty value. (`typeof null` returns `"object"` — a JavaScript quirk.)
- **`typeof`:** Checks a value's type and returns its name as a string.

```javascript
let studentName = "Dhanush";
let studentAge = 21;
let isStudent = true;

console.log(typeof studentName); // string
console.log(typeof studentAge);  // number
console.log(typeof isStudent);   // boolean
```

**Remember:** `100` is a number, but `"100"` is a string.
